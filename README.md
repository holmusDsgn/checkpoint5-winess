# Checkpoint 5 — Projeto de análise de vinhos

## Arquivos
- `Checkpoint5_Wines.ipynb`: notebook com análise estatística, gráficos, probabilidades e K-means.
- `wine.csv`: dataset de 178 amostras e 13 características químicas, com a coluna `Wine` indicando a classe original.
- `integrantes.pdf`: modelo para preencher nomes completos e matrículas.

## Como executar
1. Abra o notebook no Google Colab ou Jupyter.
2. Faça upload do notebook e do arquivo `wine.csv` (ou mantenha-os na mesma pasta).
3. Execute todas as células em ordem.
4. Confira os resultados e complete a conclusão com os valores gerados no seu ambiente.
5. Preencha o PDF com os integrantes reais e suba o notebook executado para o GitHub.

O CSV foi montado a partir do dataset Wine incluído no scikit-learn, que contém as mesmas 178 amostras e 13 características químicas do dataset clássico de vinhos referenciado no enunciado. A coluna `Wine` é a classe original e é excluída do K-means.
